二、2026 必补核心：Verl & Slime 面试深度解析

你在任何一份2025年以前的面经里，都找不到这两个框架。
但从2026年春招开始，Verl、Slime 已经成为 RLHF/对齐/Infra 岗的标准考察内容。

1. Verl：字节开源工业级 RLHF 训练框架

定位：轻量、高效、生产可用的大模型对齐全流程框架。
支持：SFT、Reward Model、PPO、DPO、GRPO、SimPO。
底层：DeepSpeed + Megatron 分布式加速。

面试高频考点

• Verl 如何实现 PPO 多阶段 pipeline？
答：分为 rollout 采样、奖励打分、优势计算、策略更新四阶段，解耦显存，支持 7B/13B 模型单卡/多卡训练。

• Verl 相比 HuggingFace TRL 优势是什么？
答：速度更快、显存更省、支持多轮对话、工业级稳定性、可直接上线。

• Verl 中如何做 显存优化？
答：ZeRO-2/3、LoRA、激活重计算、梯度累积、混合精度。

• Verl 如何解决 KL 爆炸、reward collapse？
答：动态KL系数、奖励归一化、参考模型约束、早停策略。

2. Slime：序列级大模型对齐框架

定位：清华 & 字节推出，专注长文本、多轮对话、序列级偏好对齐。
解决痛点：传统 DPO 只做 token 级监督，无法建模整段文本质量。

面试高频考点

• Slime 和 DPO 的核心区别？
答：DPO 基于 token 级对比；Slime 基于序列级全局偏好建模，长文本、创作、代码生成更稳定。

• Slime 的 loss 设计思想是什么？
答：最大化优质序列与劣质序列的对数概率差距，同时约束与基座模型的距离。

• Slime 适合哪些业务场景？
答：长文写作、多轮 Agent、代码生成、结构化输出。

• Slime 如何与 Verl 结合使用？
答：Verl 负责训练流程与分布式，Slime 负责序列级对齐 loss，形成高效对齐 pipeline。
